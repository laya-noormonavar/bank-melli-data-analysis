## 📘 Overview
This project involves analyzing a massive real-world dataset containing **22,947,011 records** from **Bank Melli Iran** to extract valuable insights about customer demographics and account distribution.

## 🔍 Key Insights
- 🧍‍♂️ Number of account holders per province  
- 🎂 Average customer age per province  
- ⚠️ Detection of anomalies (e.g., customers aged 120+ years)

## 🧰 Tech Stack
- **PostgreSQL** — complex SQL queries for data aggregation and filtering  
- **Power BI** — interactive dashboards and visual analytics
